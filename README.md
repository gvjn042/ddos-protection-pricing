## 先搞清楚 DDoS 高防 IP 到底是什么

DDoS 高防 IP 是一种托管式的 DDoS 防护服务。它不是装在你服务器上的软件,也不是某种硬件防火墙,而是一个代理式的流量清洗节点。

工作流程是这样的:

- 你把业务域名解析指向高防 IP(或者直接用 IP 指向)
- 用户访问流量先到高防 IP 节点
- 高防集群的清洗中心识别并过滤掉恶意攻击流量
- 正常流量被转发回你的源站服务器

整个过程中,你的源站 IP 是隐藏的。攻击者看到的是高防 IP,而不是你真实的服务器地址。这就是高防 IP 和高防服务器最大的区别:高防服务器是把计算资源和防护放在同一台物理机上,高防 IP 则是把流量清洗和业务部署分开——你的业务可以继续放在原来的服务器、云主机或者跨云部署,只把入口流量引到高防节点做清洗。

恒创科技在官方帮助文档里把这个流程解释得比较清楚:通过 DNS 解析将大规模攻击流量调度至高防 IP,经过高防集群清洗中心过滤,将正常访问流量转发到业务源站服务器,从而确保源站业务稳定可用。

## 什么场景适合用 DDoS 高防 IP

不是所有被攻击的情况都需要上高防 IP。根据恒创科技官方的产品选型文章,三类高防形态解决的问题不同:

| 维度 | 高防服务器 | 高防云服务器 | 高防 IP |
| --- | --- | --- | --- |
| 业务部署 | 直接部署在带防护的物理服务器 | 部署在带防护的云实例 | 业务可保留在原源站,流量经高防节点转发 |
| 迁移成本 | 需要迁移应用和数据 | 通常也需要迁移或新建实例 | 通过 DNS 或端口转发接入,不必迁移业务 |
| 源站隐藏 | 新部署时较容易控制 | 新部署时较容易控制 | 必须更换或严格限制已暴露的源站 IP |
| 适用场景 | 持续高负载、需要独占硬件 | 需要弹性和快速部署 | 已有源站、不便迁移或多云源站 |

简单说,如果你已经有一套跑得好好的业务架构,不想因为一次攻击就把整套东西搬家,高防 IP 是最合适的选择。接入只需要改 DNS 解析或者配端口转发,恒创官方的说法是最快 3 分钟可以完成部署。

但有几个前提条件你得确认:

- 你的源站 IP 如果已经被攻击者记录过,接入高防 IP 之后建议更换源站 IP,否则攻击者可以绕过高防节点直接打你的源站
- 防火墙或安全组需要配置成只允许高防回源地址访问业务端口
- 非网站类业务(比如游戏服务器、API 服务)要确认高防 IP 是否支持你用的 TCP/UDP 协议和端口

## 接入步骤:从购买到生效

1. **购买实例**:在官网选择可用区(目前为中国香港)、保底防护峰值、业务带宽、防护域名数、转发端口数和购买周期,提交订单完成支付
2. **添加网站或端口转发规则**:
   - 网站业务:在控制台添加需要防护的域名,填写源站 IP
   - 非网站业务:配置 TCP/UDP 端口转发规则,指定源站 IP 和端口
3. **修改 DNS 解析**:将域名 CNAME 记录指向高防 IP 提供的 CNAME 地址,或者将 A 记录指向高防 IP
4. **配置源站访问控制**:在源站防火墙或安全组中,只允许高防回源 IP 段访问业务端口,禁止公网直接访问源站
5. **验证防护**:通过控制台的安全监控、攻击事件和日志功能查看防护数据,确认流量已经经过高防节点

## 超过防护阈值会怎样

这个问题恒创科技在高防服务器的 FAQ 中有明确说明,高防 IP 的处理逻辑类似:

当攻击强度超出你购买的保底防护阈值,且影响到机房整体网络时,系统会自动封停你的服务器 IP。攻击停止后会自动解封,系统会通过短信或邮件通知你。

此时你有两个选择:

- **提交工单或联系客服申请手动解封**
- **升级防护**:升级后新防护秒级生效,无需增加硬件。如果你购买了弹性防护,超出保底阈值但仍在弹性范围内的攻击会自动触发弹性防护,按实际使用计费

一个重要的点:恒创官方明确表示,不会因攻击次数多或攻击持续时间长而收取额外费用。只有当攻击强度超出保底阈值且影响机房网络时才会封停,升级防护即可快速解封。

## 常见问题

**高防 IP 会改变网站 IP 吗?**

对外解析通常会指向高防 IP,用户访问到的是高防节点而不是你的源站。源站 IP 应该隐藏并限制直接访问。

**防护值越高越好吗?**

不是。过高的规格会增加成本,但如果协议不匹配、源站泄露或正常业务带宽不足,仍然会导致防护失败。应该结合历史攻击数据来选择,而不是盲目买最大的。

**接入高防 IP 后源站还会被打吗?**

如果源站 IP 仍然暴露或允许公网直接访问,攻击者可以绕过高防节点直接攻击源站。源站隐藏和访问控制是必须做的。

**CC 攻击和 DDoS 是一回事吗?**

CC 通常指应用层的高频请求攻击,DDoS 是更广泛的分布式拒绝服务概念。网络层清洗不一定自动覆盖所有复杂的应用层攻击,需要确认 WAF 和 CC 防护策略是否覆盖你的业务场景。

**"无限防御"可以理解为没有上限吗?**

不建议这样理解。任何防护服务都有单点容量、合理使用条款和超阈值处理机制,购买前应查看合同中的具体阈值和排除条件。

**恒创科技高防 IP 支持退款吗?**

不支持。官方计费说明明确指出,DDoS 高防 IP 业务不支持提前退订,完成实例购买后一概不支持退款。
